# 🌧️ ame-pomodoro

自動で作られるlofiと雨の音を聞きながら集中できるポモドーロタイマー。
`index.html` の1ファイルだけで動く。

## 機能

- ⏱️ **ポモドーロタイマー**：25分作業 → 5分休憩。4回ごとに15分の長い休憩（時間は設定で変えられる）
- 🎹 **lofi（自動生成）**：曲も音声ファイルを使わず、Web Audio APIでその場で作る。約1分半ごとに新しい曲になる。休憩中は音楽を自動で小さくできる
- 🌧️ **雨の音**：これも音声ファイルなしで、その場で作る。強さを変えられる
- 🪟 **窓の外の雨**：夜の街に雨が降るアニメーション。雨の強さと連動する
- 🔔 **チャイムと通知**：フェーズが終わるとチャイムが鳴る。設定でオンにすると、別のタブを見ているときに通知も出る
- 💾 設定はブラウザに保存される

## 使い方

| 操作 | 内容 |
|---|---|
| ▶ スタート / スペースキー | タイマーの開始・一時停止 |
| ⏭ スキップ | 今のフェーズを飛ばして次へ |
| ↺ リセット | 最初の作業からやり直す |
| ⏭ 次の曲 | 今の曲を飛ばして新しい曲を作る |

## lofiのしくみ

曲ごとに、キー・テンポ（68〜82 BPM）・コード進行・リズムをランダムに決めて、16分音符ずつ少し先の時刻に音を予約していく。

1. **エレピ（和音）**：FM合成で作った「コーン」という音で、9thや13thを含むジャズっぽい和音を弾く
2. **ベース**：和音のルートを低い音で弾く
3. **ドラム**：キックはサイン波の音程を急に下げて作り、スネアとハイハットはノイズにフィルターをかけて作る。裏拍を少し遅らせて、跳ねたリズムにしている
4. **メロディ**：曲の真ん中あたりで、ペンタトニックの音をまばらに弾く
5. **lofiっぽさ**：高い音を削る、少し歪ませる、テープのように音程をゆらす、レコードのサーッとパチパチを重ねる

## 雨の音のしくみ

3つの音を重ねている。

1. **サーッという音**：ピンクノイズから、低すぎる音と高すぎる音をフィルターで削ったもの
2. **遠くのゴーッという音**：ブラウンノイズの低い音だけを残したもの
3. **ポツッという雨粒**：短いホワイトノイズに、毎回ちがう高さのフィルターをかけて、ランダムなタイミングと左右の位置で鳴らす
