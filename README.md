# 🌧️ ame-pomodoro

Lofi Girlの配信を流しながら、雨の音を聞いて集中できるポモドーロタイマー。
`index.html` の1ファイルだけで動く。

## 機能

- ⏱️ **ポモドーロタイマー**：25分作業 → 5分休憩。4回ごとに15分の長い休憩（時間は設定で変えられる）
- 🎧 **Lofi Girl**：YouTubeの配信を埋め込んで再生。休憩中は音楽を自動で小さくできる
- 🌧️ **雨の音**：音声ファイルを使わず、Web Audio APIでその場で作る。強さを変えられる
- 🪟 **窓の外の雨**：夜の街に雨が降るアニメーション。雨の強さと連動する
- 🔔 **チャイムと通知**：フェーズが終わると鳴る。別のタブを見ているときは通知が出る
- 💾 設定はブラウザに保存される

## 使い方

| 操作 | 内容 |
|---|---|
| ▶ スタート / スペースキー | タイマーの開始・一時停止 |
| ⏭ スキップ | 今のフェーズを飛ばして次へ |
| ↺ リセット | 最初の作業からやり直す |

## 開き方

**GitHub Pagesで公開して開く**のがおすすめ。

`index.html` をダブルクリックで直接開くと、YouTubeが再生エラーになることがある（雨の音とタイマーは動く）。
手元で試すときは、このフォルダで簡単なサーバーを立てて開く。

```bash
python -m http.server
```

立てたら、ブラウザで http://localhost:8000 を開く。

## 雨の音のしくみ

3つの音を重ねている。

1. **サーッという音**：ピンクノイズから、低すぎる音と高すぎる音をフィルターで削ったもの
2. **遠くのゴーッという音**：ブラウンノイズの低い音だけを残したもの
3. **ポツッという雨粒**：短いホワイトノイズに、毎回ちがう高さのフィルターをかけて、ランダムなタイミングと左右の位置で鳴らす
